# 打工薪資小幫手 (Part-Time Salary Helper)

專為兼職與打工族群打造的響應式排班與薪資試算網頁應用（繁體中文），支援手機、平板與桌面電腦。

## 功能特色

- **多份工作管理**：可新增、編輯、停用與重新啟用多份工作（設定工作名稱、時薪、識別顏色，以及選填的預設上下班時間與不計薪休息分鐘數）。修改工作時薪只影響後續新增班次，歷史班次保留原時薪；停用工作後仍完整保留歷史班表與薪資紀錄。
- **互動式月曆與每日排班**：
  - 支援年份與月份選擇器，以及「上個月」「本月」「下個月」快速切換，正確處理大小月與閏年。
  - 桌面版點選日期開啟側邊編輯面板；手機版開啟底部觸控面板。
  - 支援同日多份工作或分段排班、跨午夜「隔日下班」班次、班次時間重疊提醒，以及取消勾選上班前的防誤刪確認。
- **分鐘級精準薪資計算與即時預覽**：
  - 以分鐘計算計薪工時（不先對工時四捨五入），單筆顯示至小數點後兩位，當月總計於加總後統一四捨五入。
  - 編輯班次時間或休息分鐘數時，右下角／底部薪資摘要即時預覽變化；按取消立即還原。
  - 可展開查看各份工作的工時與薪資小計。
- **本機儲存與 JSON 備份還原**：
  - 自動保存於瀏覽器 `localStorage`，離線重新整理不遺失。
  - 支援匯出與匯入 JSON 備份檔（含資料格式驗證與覆蓋前確認），以及刪除班次後的復原（Undo）操作。
